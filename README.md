## 🔍 Detailed Domain Overviews

<details>
<summary><b>1. Agile Task & Project Management (Trello, Jira, ClickUp)</b></summary>
<br>

* **Agile Kanban Board (Trello):** Configured continuous workflow stages (`To Do` ➔ `In Progress` ➔ `QA Testing` ➔ `Done`) with priority labels and Butler automation rules.
* **Scrum Sprint & Burndown Metrics (Jira Software):** Managed 2-week sprints, story point estimation using Fibonacci sequencing, backlog grooming, and burndown velocity metrics.
* **Interactive Project Timeline (ClickUp / GanttProject):** Modeled comprehensive Work Breakdown Structures (WBS) with dependency networks and Critical Path Method (CPM) analyses.

</details>

<details>
<summary><b>2. Business Analysis & Requirements Engineering</b></summary>
<br>

* **BPMN Process Flowchart (Bizagi Modeler):** Formulated BPMN 2.0 business process models for E-commerce checkout, payment gateways, and exception handling refund workflows.
* **Product Requirement Document & RTM (Confluence + Jira):** Authored detailed PRD specifications and mapped a bidirectional 15+ User Story Requirements Traceability Matrix (RTM).
* **User Story Mapping (Miro):** Structured functional backlogs using the MoSCoW framework across Release 1 (MVP), Release 2, and Release 3 increments.

</details>

<details>
<summary><b>3. Systems Analysis & Integration Specialist</b></summary>
<br>

* **API Blueprint & Documentation (Postman / Swagger):** Specified OpenAPI 3.0 contracts, request/response models, bearer authorization, and dynamic test assertions for payment gateways.
* **Microservices Architecture Diagram (Draw.io):** Visualized system topologies, domain class models, and multi-tier Data Flow Diagrams (DFD Level 0, 1, and 2).
* **Webhooks Integration Suite (Bruno):** Validated real-time event notifications, payload verifications, HMAC signatures, and idempotent subscriber consumers.

</details>

<details>
<summary><b>4. IT Support, Application Support & ERP Support</b></summary>
<br>

* **ITSM Service Desk Setup (Jira Service Management):** Designed ITIL-aligned service catalogs, custom request workflows, and multi-tiered SLA response/resolution rules.
* **ERP Implementation (Odoo):** Configured core modules including multi-warehouse inventory tracking, procurement rules, sales pipelines, and customer billing.
* **Log Monitoring & Bug Debugging (Postman + ELK):** Filtered production server application logs to identify, reproduce, and document Root Cause Analyses (RCA) for HTTP 4xx and 5xx API errors.

</details>

<details>
<summary><b>5. Data Analyst, DBA & Business Intelligence</b></summary>
<br>

* **Executive BI Sales Dashboard (Power BI / Metabase):** Designed interactive KPI dashboards using DAX calculations to track revenue velocity, MRR, churn rate, and cohort performance.
* **3NF Relational Database Schema (DBeaver / MySQL):** Engineered normalized relational database schemas (3NF) with constraints, indexing, and complex analytical SQL queries.
* **Customer Churn Data Analytics (Python):** Performed Exploratory Data Analysis (EDA) on customer retention using Pandas, NumPy, Matplotlib, and Seaborn.

</details>

<details>
<summary><b>6. Software Testing (Manual & Automation)</b></summary>
<br>

* **Manual Test Case Suite (TestRail / Zephyr Scale):** Designed a 50+ test scenario matrix covering boundary value analysis, positive/negative validation, and regression suites.
* **Defect Lifecycle Management (Jira):** Documented bug reports with reproduction steps, environment telemetry, log extracts, and severity/priority categorizations.
* **Web UI Automation Framework (Playwright):** Architected a Page Object Model (POM) automation suite covering end-to-end shopping and checkout workflows across Chromium, Firefox, and WebKit.

</details>

<details>
<summary><b>7. UI/UX Engineering & Design</b></summary>
<br>

* **App UI Component Design System (Figma):** Created an atomic design system with design tokens, responsive typography scales, color palettes, and auto-layout UI components.
* **Interactive High-Fidelity Prototype (Figma):** Developed a clickable mobile ordering application with micro-interactions, animated drawer transitions, and checkout flows.
* **Accessibility & Speed Audit (AXE DevTools):** Executed a WCAG 2.1 Level AA compliance audit addressing color contrast ratios, screen reader accessibility, and semantic DOM structures.

</details>
